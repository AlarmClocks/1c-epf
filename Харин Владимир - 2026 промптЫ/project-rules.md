## Структура проекта

src\cf - текущая конфигруация: Управление торговлей 11.5 + CRM (взаимоотношения с клиентами)
src\cfe_main - основное расширение конфигурации с доработками типовых объектов
src\epf - внешние подключаемые обработки
src\erf - внешние подключаемые отчеты

## Соглашения

- Префикс для добавленных объектов метаданных: **нп_**
- Префикс для добавленных реквизитов типовых объектов: **нп_**
- Новые объекты разрабатываем в основной конфигруации
- Доработки типовых объектов — в расширении src\cfe_main
- Изменение типовых форм — программным созданием элементов
- XML файлы, содержащие метаданные объектов или структуру форм - НЕ ИЗМЕНЯТЬ! Только чтение и текстовые инструкции пользователю какие изменения надо внести
